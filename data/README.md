## 32 题快测（oejts_zh.json）

题目改编自 Open Psychometrics 的 **Open Extended Jungian Type Scales 1.2**（Eric Jorgenson，<https://openpsychometrics.org/tests/OJTS/development/OEJTS1.2.pdf>），中文译文取自 [OpenJung](https://github.com/openjung/core) 项目的 `src/questions.ts`。

这些题目按 **Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International（CC BY-NC-SA 4.0）** 协议使用：<https://creativecommons.org/licenses/by-nc-sa/4.0/>

- 署名：网页的快测下方显示了出处。
- 非商业：网站收费或商用时，需要把这部分换成自己写的题目。
- 相同方式共享：本文件（包括对它的任何修改）同样按 CC BY-NC-SA 4.0 提供。

计分方式与 OpenJung 一致：每题 1–5 分，左边描述对应 E、S、F、J，右边对应 I、N、T、P；每个维度 8 题，总分大于 24 取右边的字母。
